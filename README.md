# SPL-AljabarMatriks
Aplikasi Sistem Persamaan Linear (SPL) pada pehitungan harga makanan

**Variabel:**

* \(x\) = Nasi Goreng
* \(y\) = Es Teh
* \(z\) = Ayam

**Sistem Persamaan:**

1. \(2x + y + z\) = Rp47.000 (Meja 1)
2. \(x + 2y + z\) = Rp37.000 (Meja 2)
3. \(x + y + 2z\) = Rp44.000 (Meja 3)

**Hasil Perhitungan \(X = A^{-1}B\):**

* **Nasi Goreng \(x\):** Rp15.000
* **Es Teh \(y\):** Rp5.000
* **Ayam \(z\):** Rp12.000
